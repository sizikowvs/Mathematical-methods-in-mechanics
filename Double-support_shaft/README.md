# Математические методы в задачах механики / Mathematical Methods in Mechanics

Методические материалы и программные комплексы на базе MATLAB для магистров специальности «Прикладная механика» Санкт-Петербургского государственного технологического института (Технического университета).

## Содержимое репозитория / Repository Contents

Численное решение уравнений колебаний двухопорного вала импеллерной мешалки с учетом эксцентриситета импеллера с целью определения критической частоты вращения вала методом средней точки:
1. **Data_Unbal.m** — Script-файл с исходными данными задачи.
2. **sredn_Unbal_rotor.m** — Функция решения уравнений колебаний вала методом средней точки.
3. **solution_Unbal_rotor.m** — Функция интегрирования уравнений движения на заданном интервале времени и построения графиков координаты ц.м. импеллера от времени и траектории движения ц.м. импеллера.

## Как запустить / How to Run

1. Скачайте файлы трех программ на ваш компьютер и разместите их в одной папке.
2. Откройте файлы в среде MATLAB (рекомендуется версия R2021a и новее) и при необходимости измените численные значения параметров конструкции вала и импеллера мешалки и характеристик перемешиваемой среды в файле **Data_Unbal.m**, нажав после этого кнопку **Save** (сохранить).
3. Откройте функцию **solution_Unbal_rotor.m** и нажмите кнопку **Run** (Запуск).

## Ожидаемые результаты / Expected Results
Программа выполняет интегрирование уравнений движения в неподвижной системе координат методом средней точки. На выходе генерируются:
* График координаты ц.м. диска $x(t)$ от времени с учетом действием вязкого гидродинамического демпфирования среды.
* Траектория движения центров масс импеллера в плоскости x-y в форме окружностей.
