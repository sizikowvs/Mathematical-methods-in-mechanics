# Математические методы в задачах механики / Mathematical Methods in Mechanics
Методические материалы и программные комплексы на базе MATLAB для магистров специальности «Прикладная механика» Санкт-Петербургского государственного технологического института (Технического университета).

## Содержимое репозитория / Repository Contents

Комплексная прочностная проверка трубопровода высокотемпературного газоохлаждаемого реактора (ВТГР): определение критической скорости потока, при которой трубопровод будет теряет устойчивость, и динамическая задача вибропрочности при пульсации давления от циркуляционного нагнетателя с оценкой напряжений в конструкции от действия периодических вынуждающих нагрузок (с проверкой трубопровода на усталостную прочность):
1. **Data_HTGR.m** — Script-файл с исходными данными конструкции трубопровода и применяемых сред.
2. **freq_HTGR.m** — функция определения собственных частот трубопровода ВТГР при учете различных условий нагружения.
3. **Crit_HTGR.m** — функция поиска критической скорости гелия, при которой происходит потеря устойчивости трубопровода ВТГР.
4. **solution_HTGR.m** — функция интегрирования уравнений колебаний трубопровода на заданном интервале времени и построения графиков координат и траекторий узлов трубопровода ВТГР

## Как запустить / How to Run

1. Скачайте файлы четырех программ на ваш компьютер и разместите их в одной папке.
2. Откройте файлы в среде MATLAB (рекомендуется версия R2021a и новее) и при необходимости измените численные значения параметров трубопровода ВТГР в файле **Data_HTGR.m**, нажав после этого кнопку **Save** (сохранить).
3. Откройте функцию **freq_HTGR.m** и нажмите кнопку **Run** (Запуск). В консоли будут выведены результаты расчета собственных частот изгибных колебаний "пустого" трубопровода при обычной температуре гелия и под нагревом, нагретого трубопровода с учетом добавления в конструкцию компенсирующего сильфона, а также собственных частот с учетом сил Кориолиса закрученного потока гелия.
4. Откройте функцию **Crit_HTGR.m** и нажмите кнопку **Run** (Запуск). Будут выведен результат проверки устойчивости трубопровода под действием движущегося потока гелия и (в случае потери устойчивости) значение скорости, при которой происходит потеря устойчивости.
5. Откройте функцию **solution_HTGR.m** и запустите ее кнопкой **Run** (Запуск). будут выведены графики координаты х 3-го узла трубопровода и траектория движения этого узла в плоскости xy. При необходимости построения других графиков добавьте команды построения с соответствующими координатами (или скоростями) узлов в конец функции, скопировав блоки начиная с "figure" и заканчивая "ylabel('y, м');".

## Ожидаемые результаты / Expected Results
Программа выполняет поиск частот свободных колебаний трубопровода ВТГР методом конечных элементов и встроенной функции Matlab поиска собственных значений матриц, определяет критическую скорость потока гелия, при которой трубопровод теряет устойчивость (по критерию появления в спектре собственных чисел системы члена с положительной вещественной частью) и решает уравнение вынужденных колебаний трубопровода под действием периодической силы от циркуляционного нагнетателя рабочего вещества.
На выходе генерируются:
* значения частот собственных колебаний трубопровода;
* критическая скорость движения гелия, соответствующая потере устойчивости трубопровода;
* График координаты узла трубопровода и траекторий его движения в плоскости.
