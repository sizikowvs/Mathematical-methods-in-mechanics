# Математические методы в задачах механики / Mathematical Methods in Mechanics

Методические материалы и программные комплексы на базе MATLAB для магистров специальности «Прикладная механика» Санкт-Петербургского государственного технологического института (Технического университета).

## Содержимое репозитория / Repository Contents

Численный расчет изгибных колебаний и пространственной прецессии вала двухъярусной импеллерной мешалки в жидкой среде методом конечных элементов (МКЭ, матрицы 8х8) и неявным методом средней точки:
1. **Data_Multisup_Shaft.m** — Script-файл Data_Multisup_Shaft с исходными данными задачи.
2. **sredn_Multisup_Shaft.m** — Функция решения уравнений колебаний вала методом средней точки.
3. **solution_Multisup_Shaft.m** — Функция интегрирования уравнений движения на заданном интервале времени и построения графиков с решением.
4. **FFT_alg.m** — Функция поиска собственных частот изгибных колебаний вала импеллерной мешалки быстрым преобразованием Фурье.

## Как запустить / How to Run

1. Скачайте файлы `Rotor_Dynamics_2Disks.m` на ваш компьютер и разместите их в одной папке.
2. Откройте файлы в среде MATLAB (рекомендуется версия R2021a и новее) и при необходимости измените численные значения параметров мешалки в файле "Data_Multisup_Shaft.m", нажав после этого кнопку **Save** (cj[hfybnm).
3. Откройте функцию "solution_Multisup_Shaft.m" и нажмите кнопку **Run** (Запуск).

## Ожидаемые результаты / Expected Results
Программа выполняет интегрирование уравнений движения в неподвижной системе координат. На выходе генерируются:
* График затухающих биений координаты $x(t)$ от времени под действием вязкого гидродинамического демпфирования Рэлея.
* Пространственные траектории движения центров масс импеллеров $y(x)$ в форме закручивающихся к центру эллиптических спиралей (прецессия ротора).
* Амплитудно-частотный спектр сигнала, полученный с помощью быстрого преобразования Фурье (FFТ), с четкой фиксацией двух изгибных собственных частот неподвижного вала.
