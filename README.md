# Математические методы в задачах механики / Mathematical Methods in Mechanics

Методические материалы и программные комплексы на базе MATLAB для магистров специальности «Прикладная механика» Санкт-Петербургского государственного технологического института (Технического университета).

## Содержимое репозитория / Repository Contents

1. **Rotor_Dynamics_2Disks.m** — Численный расчет изгибных колебаний и пространственной прецессии вала двухъярусной импеллерной мешалки в жидкой среде методом конечных элементов (МКЭ, матрицы 8х8) и неявным методом средней точки.

## Как запустить / How to Run

1. Скачайте файл `Rotor_Dynamics_2Disks.m` на ваш компьютер.
2. Откройте файл в среде MATLAB (рекомендуется версия R2021a и новее).
3. Нажмите кнопку **Run** (Запуск).

## Ожидаемые результаты / Expected Results
Программа выполняет интегрирование уравнений движения в неподвижной системе координат. На выходе генерируются:
* График затухающих биений координаты $x(t)$ от времени под действием вязкого гидродинамического демпфирования Рэлея.
* Пространственные траектории движения центров масс импеллеров $y(x)$ в форме закручивающихся к центру эллиптических спиралей (прецессия ротора).
* Амплитудно-частотный спектр сигнала, полученный с помощью быстрого преобразования Фурье (FFТ), с четкой фиксацией двух изгибных собственных частот неподвижного вала.
