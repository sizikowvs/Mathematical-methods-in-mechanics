# Математические методы в задачах механики / Mathematical Methods in Mechanics
Методические материалы и программные комплексы на базе MATLAB для магистров специальности «Прикладная механика» Санкт-Петербургского государственного технологического института (Технического университета).

## Содержимое репозитория / Repository Contents

Определение собственных частот изгибных колебаний консольного вала импеллерной мешалки с учетом гироскопических моментов:
1. **Data_Console.m** — Script-файл с исходными данными консольного вала и импеллера мешалки.
2. **Roots_Console.m** — функция определения частот собственных колебаний ротора с импеллером.
3. **sredn_Console_Shaft.m** — функция  решения уравнений колебаний вала методом средней точки.
4. **solution_Console_Shaft.m** — функция интегрирования уравнений колебаний импеллера на консольном валу на заданном интервале времени и построения графиков координат и траекторий движения импеллера

## Как запустить / How to Run

1. Скачайте файлы четырех программ на ваш компьютер и разместите их в одной папке.
2. Откройте файлы в среде MATLAB (рекомендуется версия R2021a и новее) и при необходимости измените численные значения параметров вала мешалки и импеллера в файле **Data_Console.m**, нажав после этого кнопку **Save** (сохранить).
3. Откройте функцию **Roots_Console.m** и нажмите кнопку **Run** (Запуск) для определения собственных частот свободных изгибных колебаний вала.
4. Откройте функцию **solution_Console_Shaft.m** и запустите ее кнопкой **Run** (Запуск). В результате будут выведены графики координаты х центра масс импеллера и траектория его движения в плоскости xy. При необходимости построения других графиков (углов поворота или скоростей движения импеллера) добавьте команды построения с соответствующими координатами (или скоростями) узлов в конец функции, скопировав и видоизменив блоки начиная с "figure" и заканчивая "ylabel('y_C, м');".

## Ожидаемые результаты / Expected Results
Программа выполняет поиск частот собственных колебаний импеллера одноопорного консольного вала перемешивающего устройства для жидких сред. Решением характеристического уравнения системы определяются частоты его свободных колебаний импеллера с учетом действия гироскопических моментов; методом средней точки решается уравнение колебаний импеллера при вращении вала и определяются линейные координаты вала, углы его поворота и соответствующие скорости.
На выходе генерируются:
* значения частот собственных колебаний импеллера на консольном валу с учетом гироскопического эффекта;
* график координаты ц.м. импеллера мешалки и траекторий его движения в плоскости xy.
