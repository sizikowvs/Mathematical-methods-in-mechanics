# Математические методы в задачах механики / Mathematical Methods in Mechanics
Методические материалы и программные комплексы на базе MATLAB для магистров специальности «Прикладная механика» Санкт-Петербургского государственного технологического института (Технического университета).

## Содержимое репозитория / Repository Contents

Динамический хаос и нелинейные колебания центрифуг для разделения суспензий:
1. **Data_Centrifuge.m** — Script-файл с исходными данными параметров конструкции ФГП центрифуги и режимом ее вращения.
2. **duff_Centrifuge.m** — функция решения уравнений колебания ротора центрифуги.
3. **solution_Centrifuge.m** — функция интегрирования уравнения движения и построения диаграмм: траекторий, фазового портрета, сечений Пуанкаре для нелинейных колебаний ротора центрифуги ФГП, странного аттрактора.
4. **Bif_diagram.m** — функция построения бифуркационной диаграммы ФГП центрифуги 

## Как запустить / How to Run

1. Скачайте файлы четырех программ на ваш компьютер и разместите их в одной папке.
2. Откройте файлы в среде MATLAB (рекомендуется версия R2021a и новее) и при необходимости измените численные значения параметров центрифуги в файле **Data_Centrifuge.m**, нажав после этого кнопку **Save** (сохранить).
3. Откройте функцию **solution_Centrifuge.m** и нажмите кнопку **Run** (Запуск) для решения уравнений движения и построения диаграмм. Для трех режимов будут построены траектории ц.м. ротора, фазовые портреты, сечения Пуанкаре, странный аттрактор. Параметры расчета можно менять внутри функции, изменяя значения эксцентриситетов центрифуги с материалом, времени расчета траектории в при обращении к решению "solution_Centrifuge.m" и диапазоны вывода переменных в соответствующих командах вывода графиков "plot".
4. Откройте функцию **Bif_diagram.m** и запустите ее кнопкой **Run** (Запуск). Будет построена бифуркационная диаграмма работы центрифуги.

ИЗМЕНИТЬ!!!## Ожидаемые результаты / Expected Results
!!!Программа выполняет поиск частот собственных колебаний импеллера одноопорного консольного вала перемешивающего устройства для жидких сред. Решением характеристического уравнения системы определяются частоты его свободных колебаний импеллера с учетом действия гироскопических моментов; методом средней точки решается уравнение колебаний импеллера при вращении вала и определяются линейные координаты вала, углы его поворота и соответствующие скорости.
На выходе генерируются:
* значения частот собственных колебаний импеллера на консольном валу с учетом гироскопического эффекта;
* график координаты ц.м. импеллера мешалки и траекторий его движения в плоскости xy.
