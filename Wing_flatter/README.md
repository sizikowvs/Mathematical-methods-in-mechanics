# Математические методы в задачах механики / Mathematical Methods in Mechanics
Методические материалы и программные комплексы на базе MATLAB для магистров специальности «Прикладная механика» Санкт-Петербургского государственного технологического института (Технического университета).

## Содержимое репозитория / Repository Contents

Поиск критической скорости набегающего потока воздуха при изгибно-крутильных колебаниях крыла (флаттере):
1. **Data_Flatter.m** — Script-файл с исходными данными крылового профиля и набегающего воздушного потока.
2. **sredn_Flatter.m** — функция определения собственных частот трубопровода ВТГР при учете различных условий нагружения.
3. **solution_flatter.m** — функция интегрирования уравнений движения на заданном интервале времени и построения графиков колебаний угла закручивания крыла и прогиба

## Как запустить / How to Run

1. Скачайте файлы четырех программ на ваш компьютер и разместите их в одной папке.
2. Откройте файлы в среде MATLAB (рекомендуется версия R2021a и новее) и при необходимости измените численные значения параметров трубопровода ВТГР в файле **Data_Flatter.m**, нажав после этого кнопку **Save** (сохранить).
3. Откройте функцию **solution_flatter.m** и нажмите кнопку **Run** (Запуск). Будут выведены графики угла закручивания крыла во времени и прогиба крыла во времени, по которым можно установить, являются ли колебания затухающими (докритическая скорость), нарастающими (закритическая скорость) или установившимися (критическая скорость).

## Ожидаемые результаты / Expected Results
Программа с помощью метода средней точки интегрирует уравнения колебаний крыла в дозвуковом потоке и при заданных характеристиках крылового профиля и потока воздуха позволяет определить критическую скорость, на которой возникает флаттер (изгибно-крутильные колебания крыла). В математической модели учтено демпфирующее действие потока воздуха.
На выходе генерируются графики угла закручивания и вертикального прогиба крыла во времени.
